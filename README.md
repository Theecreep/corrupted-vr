# CORRUPTED v0.01

A genuine 3D ASCII island exploration prototype for desktop browser and Quest WebXR.

Desktop: WASD move, mouse or arrow keys look, E listen, Shift run, Escape pause, R restart.
Quest: ENTER VR, left stick move, right stick snap turn, trigger listen. Quest hardware testing remains pending.

Collect three amber echoes and return to the breach. No build step or CDN required. Three.js r170 is bundled with its MIT license in THREE-LICENSE.txt.
